refactor

Plan safe edits to Python files: find and replace, extract, inline, and moving a definition to another file.

Edits

A plan is a list of FileEdit objects, one per file: the path, the whole text before, the whole text after, and the number of changes. To apply a plan, write each after; to undo it, write each before back. A before of None means the plan creates the file, so undoing it means deleting the file.

FileEdit

def FileEdit(
    path:str, before:str, after:str, edits:int
)->None:

One file’s whole text before and after, so a plan can be shown, applied, and undone.

FileEdit('a.py', 'x = 1\n', 'y = 1\n', 1).dict()
{'path': 'a.py', 'before': 'x = 1\n', 'after': 'y = 1\n', 'edits': 1}

Text replacement

replace_plan(paths, query, replacement) is find and replace across files. The search is literal and case-insensitive by default. regex=True treats query as a regular expression, and replacement may then refer to groups. case=True makes the match case-sensitive, and word=True matches whole words only, which is why koshas survives in the example below. It returns the changed files and a list of skipped paths.

It takes a list of paths and a read function, not a directory, so it can work on the files on disk, on a git revision, or on an editor’s unsaved buffers. Notebooks are skipped, and so is any file that cannot be read or that holds the Unicode replacement character, which is what a binary file turns into when read as text. Skipping it is better than corrupting it.

replace_plan

def replace_plan(
    paths, query, replacement, regex:bool=False, case:bool=False, word:bool=False, read:function=_read
):

Plan one find-and-replace across paths: the changed files as FileEdits, and the paths skipped.

with TemporaryDirectory() as d:
    root = _tree(d, {'a.py': 'kosha = 1\nprint(koshas)\n', 'b.py': 'x = 2\n', 'nb.ipynb': '{}'})
    rows, skipped = replace_plan(sorted(root.iterdir()), 'kosha', 'kosha2', word=True)
    print([Path(r.path).name for r in rows], [Path(p).name for p in skipped])
    print(rows[0].after)
['a.py'] ['nb.ipynb']
kosha2 = 1
print(koshas)

Symbols and their spans

The planners cut and paste text by character position. Python’s ast module reports positions as a line number and a column, and the column counts UTF-8 bytes, not characters, so a line with an accented letter would put every later column off. The private helpers here convert positions to character offsets correctly.

top_symbols lists a file’s top-level functions and classes, each with the span of text it owns. A definition owns more than its own lines. The comment block just above it and its decorators belong to it, and so do the blank lines below it, so that removing it does not leave a gap. The example shows sep taking its comment and its @cache decorator with it.

top_symbols

Top-level functions and classes, each with the character span it owns.

SRC = '''import os

# the separator, repeated
@cache
def sep(n): return os.sep * n


class Thing:
    def go(self): return sep(1)
'''
top_symbols(SRC)
[{'name': 'sep', 'kind': 'function', 'line': 5, 'start': 11, 'end': 76},
 {'name': 'Thing', 'kind': 'class', 'line': 8, 'start': 76, 'end': 121}]
sym = top_symbols(SRC)[0]
print(SRC[sym['start']:sym['end']])

@cache
def sep(n): return os.sep * n

Naming the module a file is

module_of turns a file path into the dotted module name an import would use. It climbs from the file to its import root with kosha.core.imp_root, the same rule the index uses for mod_name, so the two always agree. A package’s __init__.py is the package itself, pkg, not a submodule pkg.__init__.

Dotted module name for a file, from the top of its __init__.py chain.

with TemporaryDirectory() as d:
    root = _tree(d, {'pkg/__init__.py': '', 'pkg/sub/__init__.py': '', 'pkg/sub/deep.py': '', 'loose.py': ''})
    print([module_of(root/p) for p in ('pkg/sub/deep.py', 'pkg/__init__.py', 'loose.py')])
['pkg.sub.deep', 'pkg', 'loose']

Free names

Moving code is safe only if every name it reads but does not define is still available where it lands. These are its free names. In the example, the function reads BASE and os from its module, so whatever file it moves to must provide them. len is left out because it is a builtin, and n and total are defined inside the function.

The builtins are left out by default. A module that defines its own filter or id must not leave them out, or the check would treat a call to its own filter as satisfied by the builtin. move_plan handles that case, shown further down.

_body = ast.parse('def f(n):\n    total = BASE\n    return len(total) + n + os.sep\n').body
print(sorted(_free(_body)), '|', sorted(_free(_body, exclude=()) & {'len'}))
['BASE', 'os'] | ['len']

Extract

extract(path, source, start, end, kind, name) takes the text between character offsets start and end and lifts it into something new called name. kind is one of four values:

  • 'function': the selected whole statements become a nested function defined in place, followed by a call to it.
  • 'method': the same, but the new method goes into the class, after the method the selection came from.
  • 'variable': the selected expression is assigned to name on the line above and replaced by name.
  • 'constant': a literal value at module level becomes an UPPER_CASE constant placed after the docstring and the imports.

It refuses a selection it cannot lift safely and raises a ValueError saying why: part of a statement, or statements that return or yield, since those would change meaning inside a new function.

extract

def extract(
    path, source, start, end, kind, name
):

Plan lifting the selection start:end of source into a new function, method, variable or constant called name.

The new function’s parameters are the names the selection reads before it assigns them. Its return values are the names it assigns that the code after the selection still reads. Everything else stays local to the new function. Here rows becomes a parameter and total, which print reads afterwards, comes back as the return value.

F = '''def report(rows):
    total = 0
    for r in rows: total += r
    print(total)
'''
sel = F.index('    total = 0'), F.index('total += r') + len('total += r')
print(extract('r.py', F, *sel, 'function', 'tally').after)
def report(rows):
    def tally(rows):
        total = 0
        for r in rows: total += r
        return total

    total = tally(rows)

    print(total)

An extracted method is placed beside the method it came from, not inside it, because the call self.step() needs step to be a method of the class.

M = '''class Report:
    def show(self):
        total = self.rows + 1
        print(total)
'''
print(extract('m.py', M, M.index('        total'), M.index('+ 1') + 3, 'method', 'step').after)
class Report:
    def show(self):
        total = self.step()

        print(total)

    def step(self):
        total = self.rows + 1
        return total

Inline

inline(path, source, pos) is the reverse of extracting a variable. Put pos on any use of a variable that is assigned exactly once, as a plain name = value on lines of its own, and it replaces every use with the value and deletes the assignment. A value that is more than a single name, call, literal or similar is wrapped in parentheses, so width = 1 + 2 inlined into width * 3 gives (1 + 2) * 3 and not 1 + 2 * 3. It refuses variables assigned more than once, declared global or nonlocal, never read, or read before they are assigned.

inline

def inline(
    path, source, pos
):

Replace a variable’s uses with its value and delete the assignment.

I = 'width = 1 + 2\nprint(width * 3, width)\n'
inline('i.py', I, I.index('width')).after
'print((1 + 2) * 3, (1 + 2))\n'

Imports

When a move adds an import, the import should look like one a person would write. If the importing module and the target share a package, the import is relative: inside pkg.c, the module pkg.b is imported as from .b import .... With nothing in common it stays absolute. Going the other way, an existing relative import is resolved against the module that holds it, so from .a import x inside pkg.c and from pkg.a import x inside pkg.d are recognised as imports of the same module.

print(_stmt('pkg.b', 'pkg.c', ['shared']))          # same package: relative
print(_stmt('other.b', 'pkg.c', ['shared']))        # nothing shared: absolute
print(_absolute(ast.parse('from .a import x').body[0], 'pkg.c'))
from .b import shared
from other.b import shared
pkg.a

A new import joins the file’s existing imports. If the file already has a from import of the same module, the name is added to it instead of repeating the module. Anything new goes below the module docstring, the imports and the __all__ that an nbdev module starts with.

_t = '"doc"\nimport os\nfrom pkg.b import one\n\nprint(one)\n'
_p = _parse('c.py', _t)
print(_apply(_t, _add_imports(_t, _p, _starts(_t), 'pkg.c', {'pkg.b': {'two'}, 'pkg.d': {'three'}}, {'import sys'})))
"doc"
import os
from .b import one, two
from .d import three
import sys

print(one)

Moving a definition

A move must also keep each module’s __all__, its list of public names, correct. kosha rewrites __all__ when it is a plain list or tuple of strings. When it is built any other way, such as ['x'] + more, it is left alone, because rewriting it would mean guessing.

Every file that imported a moved name has to import it from its new home. There are two shapes to fix. A from src import name statement is split, so the names that stayed keep the old import and the moved ones get a new import. An import src statement used as src.name is rewritten to a direct import of name, and the import src line is removed only when nothing else in the file uses it. A file that already defines a name of its own with the same name is left alone, with a note, because rewriting its uses would point them at the wrong definition.

move_plan(src, names, dest, others) puts all of this together. It cuts the named top-level functions and classes out of src, with the comments and decorators they own, and appends them to dest, creating dest if needed. The imports the moved code relies on are copied into dest, and names it reads from src itself are imported back from src. By default src keeps a re-export, an import of the moved names from dest, so code that still imports them from src keeps working; shim=False leaves it out. Every file in others that imported the names is repointed to dest.

Before returning, it checks every file in the plan for names that the edit would leave undefined, and raises a ValueError naming the file and the names if there are any. It returns the plan and a list of notes about things it chose not to do.

A move, end to end

The example project has three files in package pkg. a.py defines shared, b.py is where it is going, and c.py imports it by name. show prints each file of the plan as it would be after the move.

PROJECT = {'pkg/__init__.py': '',
           'pkg/a.py': '''
                "paths"
                import os

                def helper(x): return x + 1

                # the separator, repeated
                def shared(n): return os.sep * n
                ''',
           'pkg/b.py': '"where shared is going"\n',
           'pkg/c.py': 'from pkg.a import helper, shared\n\nprint(shared(2), helper(1))\n'}

def show(rows, notes=()):
    for r in rows: print(f'==== {Path(r.path).name} ' + ('(new) ' if r.before is None else '') + '='*20); print(r.after)
    for n in notes: print('note:', n)
with TemporaryDirectory() as d:
    root = _tree(d, PROJECT)
    rows, notes = move_plan(root/'pkg/a.py', ['shared'], root/'pkg/b.py', others=[root/'pkg/c.py'])
    show(rows, notes)
==== a.py ====================
"paths"
import os
from .b import shared

def helper(x): return x + 1

==== b.py ====================
"where shared is going"
import os


# the separator, repeated
def shared(n): return os.sep * n

==== c.py ====================

from .b import shared

a.py keeps a re-export, so code that imported shared from it still works. With shim=False the re-export is left out, and then only the files listed in others keep working.

    rows, notes = move_plan(root/'pkg/a.py', ['shared'], root/'pkg/b.py', others=[root/'pkg/c.py'], shim=False)

def helper(x): return x + 1

The hard cases

c.py uses import pkg.a and reaches the moved function as pkg.a.shared. That use becomes a direct import of shared from pkg.b, and the import pkg.a line stays because c.py still reads pkg.a.helper. e.py imports the module under an alias, and f.py imports shared relatively; both are repointed too.

with TemporaryDirectory() as d:
    root = _tree(d, dict(PROJECT, **{'pkg/c.py': 'import pkg.a\n\nprint(pkg.a.shared(2), pkg.a.helper(1))\n',
                                     'pkg/e.py': 'import pkg.a as pa\n\nprint(pa.shared(2))\n',
                                     'pkg/f.py': 'from .a import shared\n\nprint(shared(2))\n'}))
    others = [root/'pkg/c.py', root/'pkg/e.py', root/'pkg/f.py']
    rows, notes = move_plan(root/'pkg/a.py', ['shared'], root/'pkg/b.py', others=others)
    show(rows[2:], notes)
==== c.py ====================
import pkg.a
from .b import shared

print(shared(2), pkg.a.helper(1))

==== e.py ====================
from .b import shared

print(shared(2))

==== f.py ====================
from .b import shared

print(shared(2))

A definition with the same name as a builtin is where a check based only on names goes wrong. Moving filter out of a.py means a.py must import it back, since use still calls it. A check that ignored builtins would decide filter was always available and skip the import, and use would quietly call the builtin filter instead. move_plan gets this right.

SHADOW = {'pkg/__init__.py': '',
          'pkg/a.py': 'def filter(xs): return [x for x in xs if x]\n\ndef use(xs): return len(filter(xs))\n',
          'pkg/b.py': '"where filter is going"\n'}

with TemporaryDirectory() as d:
    root = _tree(d, SHADOW)
    rows, notes = move_plan(root/'pkg/a.py', ['filter'], root/'pkg/b.py', shim=False)
    print(rows[0].after)
from .b import filter

def use(xs): return len(filter(xs))

A move that would make two modules import each other is refused. Here the moved shared reads BASE from a.py, and helper, which stays in a.py, calls shared. Then b.py imports from a.py and a.py from b.py, which Python cannot load, so the error asks for BASE to be moved as well.

CIRCULAR = {'pkg/__init__.py': '',
            'pkg/a.py': 'BASE = 3\n\ndef shared(n): return BASE * n\n\ndef helper(x): return shared(x) + 1\n',
            'pkg/b.py': '"b"\n'}

with TemporaryDirectory() as d:
    root = _tree(d, CIRCULAR)
    test_fail(lambda: move_plan(root/'pkg/a.py', ['shared'], root/'pkg/b.py'),
              contains='pkg.a and pkg.b would import each other over BASE')
    print('refused')
refused

If nothing left in the source calls the moved definition, there is no real cycle. The only import back is b.py reading BASE, so the plan simply leaves the re-export out of a.py and adds a note saying so.

with TemporaryDirectory() as d:
    root = _tree(d, dict(CIRCULAR, **{'pkg/a.py': 'BASE = 3\n\ndef shared(n): return BASE * n\n\ndef helper(x): return x + 1\n'}))
    rows, notes = move_plan(root/'pkg/a.py', ['shared'], root/'pkg/b.py')
    show(rows, notes)
==== a.py ====================
BASE = 3

def helper(x): return x + 1

==== b.py ====================
"b"
from .a import BASE


def shared(n): return BASE * n

note: re-export left out: pkg.b imports BASE back from pkg.a

Several definitions can move at once. They keep their order from the source file, and a class moves with all its methods. __all__ is updated in both files.

MANY = {'pkg/__init__.py': '',
        'pkg/a.py': "__all__ = ['helper', 'shared', 'Thing']\nimport os\n\n"
                    "def helper(x): return x + 1\n\ndef shared(n): return os.sep * n\n\n"
                    "class Thing:\n    def go(self): return shared(1)\n",
        'pkg/b.py': "__all__ = ['already']\n\ndef already(): pass\n"}

with TemporaryDirectory() as d:
    root = _tree(d, MANY)
    rows, notes = move_plan(root/'pkg/a.py', ['shared', 'Thing'], root/'pkg/b.py', shim=False)
    show(rows, notes)

__all__ = ['helper']
import os

def helper(x): return x + 1

==== b.py ====================
